# JobShield AI

**Trace recruitment claims to evidence before you trust the offer.**

JobShield AI is an evidence-led recruitment verification prototype built by Faith Wright for the Global Innovation Build Challenge V2.

## Principle

**AI investigates, humans decide.**

JobShield helps a jobseeker preserve what was actually said, review extracted claims, identify evidence-backed warning signs, and choose independent verification steps. It does **not** declare a recruiter, person, or job offer fraudulent.

## Core workflow

Source → Evidence → Human confirmation → Deterministic rules → NOTICE / MEANING / ACTION → Case report

## MVP features

- Paste a recruitment message for analysis
- Preserve the original source text
- Extract and review candidate claims
- Human confirmation before findings
- Evidence-backed NOTICE / MEANING / ACTION findings
- Pressure-pattern timeline
- No invented payment request or unsupported allegation
- Downloadable case report
- Optional UK company-verification pathway
- Clear limitations and safe next steps

## Demo scenario

The included fictional **BrightPath WhatsApp Offer (JS-001)** demonstrates that warning signs can exist without a payment request. If the source does not contain a payment request, JobShield must not invent one.

## Safety and governance

- Human-in-the-loop review
- Evidence traceability
- Deterministic, versioned assessment rules
- Uncertainty is preserved
- Company-record matches are not treated as proof that a recruiter is authorised
- Educational investigation aid, not a legal determination or automatic fraud-reporting service

## Stack

Hackathon MVP: browser-based HTML/CSS/JavaScript implementation for a fast, inspectable public demo. The architecture is designed to migrate to Next.js + TypeScript while preserving the same evidence and governance model.
